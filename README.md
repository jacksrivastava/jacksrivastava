## Selected builds

### ✦ [AI Fashion Twin](https://github.com/jacksrivastava/AI-Fashion-Twin)
**Bring-your-own-key generative-AI fashion platform**

Create an AI avatar, paste a shopping link, and preview outfits. Built with **Next.js 15**, **React**, and **TypeScript**, with Supabase for authentication, database, and storage. Provider keys are encrypted server-side; the product includes Zod validation and automated coverage with Vitest, Testing Library, and Playwright.

### ✦ [Reddit Video Generator](https://github.com/jacksrivastava/RedditVideoGenerator)
**Automated content-generation experiment**

An educational Python workflow that queries AskReddit posts and comments, then generates an MP4 video automatically—an exploration of turning data into repeatable media output.

### ✦ [Automation Testing Framework — Proof of Concept](https://github.com/jacksrivastava/proof-of-concept-for-testing-framework)
**Reliable UI-test architecture**

A modular Java and Selenium framework using Cucumber, JUnit, Maven, and ExtentReports. It combines Page Object Model design, configurable local or remote execution, and screenshot-rich reporting for clear, reusable end-to-end tests.
